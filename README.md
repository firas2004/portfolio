# Firas Adel — 3D IoT & Systems Engineering Portfolio

Interactive 3D portfolio of **Firas Adel**, IoT Engineering Student (Faculté des Sciences de Tunis / Université de Tunis El Manar). Built with React 18, Three.js / React Three Fiber, Framer Motion, and TypeScript.

## 🚀 Features

- **Interactive 3D Hardware Lab**: Real-time procedural 3D models (STM32 development board, Cloud rack server, Smart battery module, Soil sensor module, and AI Core).
- **Dual Language**: Instant English & French translation switch.
- **Rich Experience & Education**: Showcasing engineering internships at **3S Standard Sharing Software** and **AsteelFlash**, along with academic background at FST Tunis & UTM.
- **Project Case Studies**: In-depth breakdown of PulseCity (Cloud Native IoT), Sub-1 GHz RF firmware & industrial vision, Smart Energy monitoring, and CloudStack IaaS.
- **Direct CV Download**: Integrated PDF download.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Vanilla CSS design system
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Motion & UI**: Framer Motion, Lucide Icons

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/firas2004/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
